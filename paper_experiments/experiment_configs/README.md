# Paper configurations

`paper/` stores the captured configurations and submission manifests for the
four raw paper result roots. These files retain historical absolute paths as
provenance.

The replicate-1 factorial directory also contains manifests and captured
configs for the same-protocol sample-count and learned-acquisition development
comparison documented under
`../../project_archive/results/legacy_experiments/deterministic_single_model_vs_learned_expert_bank/`.

For a portable rerun, use `../scripts/run_paper_experiments.py`; it maps the
same method settings to repository-relative maps, fixed test sets, the runtime
bundle, and externally generated RSSI traces.
