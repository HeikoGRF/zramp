# Historical model-sharing method development

These packages contain the larger method implementations used before the final
paper design:

- `place_wallis_benchmark/`: one-map development of RBF, capsule, plane,
  support-bank, dominance, cell-grid, and learned-selection variants;
- `support_acquisition_pretraining/`: learned representations for predicting
  useful support/model acquisitions;
- `support_expert_bank/`: early Expert Bank implementation; and
- `capsule_*` and `rbf_greedy/`: earlier support-shape prototypes.

The corresponding evidence is indexed in
[`results/legacy_experiments`](../../../../results/legacy_experiments/README.md).
