# Early Munich experiments

These files are the earliest end-to-end prototypes for local learning, model
sharing, central training, full fine-tuning, and zone-aware comparisons on the
Munich setup. They predate the final Luxembourg replay protocol and are kept as
development provenance rather than comparable paper evidence.

The retained outputs and their limitations are documented under
[`munich_early_benchmarks`](../../../results/legacy_experiments/munich_early_benchmarks/).
