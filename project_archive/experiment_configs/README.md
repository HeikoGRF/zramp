# Archived exploratory configurations

`experimental/` indexes captured configurations and submission manifests for
the historical campaigns. Its campaign directory names match those under
`../results/legacy_experiments/`, including the synthetic-map and real-Luxembourg online local-validation
studies and the two cross-map policy-generalization studies.

These files retain original absolute cluster paths as provenance. Map those
paths to `../../paper_experiments/input_data/` and an external output directory
when rerunning.

Paper configurations are kept once under
`../../paper_experiments/experiment_configs/paper/`.
