# Kirchberg online private-validation policy configurations

These are captured standalone configuration files copied from the preserved
historical run directories. Directory dimensions identify the method, seed,
and sweep setting. Read
`../../../results/legacy_experiments/kirchberg_online_private_validation_policy/README.md` before using them;
that file states the scientific status, omissions, and reproduction limits.

Absolute cluster paths are retained as provenance and must be remapped for a
new environment. New outputs should be written outside the repository.
